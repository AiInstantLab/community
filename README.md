# Ai Instant 社区

Ai Instant 的讨论区入口。帖子都在 [Discussions](https://github.com/aiinstantlab/community/discussions) 里。

## 可以聊什么

- **问答**：日课、趋势里没看懂的地方，直接问。
- **选题**：想听哪个原理讲透，想看哪类产品被拆开算账。
- **纠错**：日课和趋势里写错的数字、链接、结论，欢迎指出。改完会在原文注明。
- **分享**：你用 AI 做出来的东西。

## 三条规矩

1. 对事不对人。
2. 引用数据和结论，附上来源链接。
3. 不发广告，不引流。
